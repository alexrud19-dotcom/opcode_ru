## Что это

Это сборка [opcode](https://github.com/winfunc/opcode) с переведённым на русский язык
интерфейсом и установщиком под Windows, которого в исходном проекте не было.

opcode — десктопное приложение поверх Claude Code: управление проектами и сессиями, свои
агенты, MCP-серверы, контрольные точки, статистика расхода токенов. Само по себе оно
Claude Code не заменяет — это оболочка к уже установленному CLI.

## Чем отличается от оригинала

| | Оригинал | Эта сборка |
|---|---|---|
| Установщик для Windows | нет | NSIS `.exe`, интерфейс установки на русском |
| Язык интерфейса | только английский | русский по умолчанию, английский переключением |
| Сборка в CI | Linux + macOS | Windows x64 |

Язык меняется в **Настройки → Общие → Язык интерфейса**; выбор запоминается между запусками.

## Установка

Возьмите `.exe` из [релизов](../../releases) и запустите.

Установщик не требует прав администратора и ставит программу в профиль текущего
пользователя. Рядом с файлом в релизе лежит сумма `.sha256` — по ней можно проверить,
что скачалось без повреждений.

Для работы нужен установленный [Claude Code](https://claude.com/claude-code).

## Сборка из исходников

Понадобятся [Bun](https://bun.sh), [Rust](https://rustup.rs) (тулчейн MSVC) и
Visual Studio Build Tools с компонентом «Desktop development with C++».

```bash
bun install
bun run tauri build --bundles nsis
```

Готовый установщик появится в `src-tauri/target/release/bundle/nsis/`.

Собрать можно и без локального тулчейна — через GitHub Actions: вкладка **Actions** →
**Сборка Windows** → **Run workflow**, установщик окажется в артефактах запуска.

## Как устроен перевод

Строки вынесены в словари `src/lib/i18n/locales/ru.json` и `en.json`, в коде вместо текста
стоят вызовы `t('ключ')`. Инициализация — `src/lib/i18n/index.ts`.

Чтобы добавить язык: положите рядом ещё один JSON, зарегистрируйте его в `SUPPORTED_LANGUAGES`
и в `resources` при инициализации.
